ClickRow help

Draft · a short guide to ClickRow – Auto Clicker & Form Filler

In short: a task is a list of rows (click, type, choose, tick, wait…) that ClickRow runs on the current page, once or for many rounds. Everything runs in your browser.

1. Make a task

  • Pick to click — open the ClickRow popup, press Pick to click, then click the element on the page. Each pick adds a row.
  • Record — press Record and use the page normally; clicks, typing and choices become rows. Passwords and card numbers are saved as {{ask}}, never as the value.
  • Scan form — turns every field of the form on this page into one task, filled with test data or the values already on the page.
  • Templates — the + button → From a template…. Open a template to see what each row does; its generic selectors are under Advanced. Re-pick elements in the editor if they don’t match your page.

2. Run, repeat and stop

  • Press the round play button on a task. A small ClickRow bar on the page shows the current round and row, with Pause and Stop.
  • In the editor, Repeat sets how many rounds to run, the pause between rounds, or “until an element is gone”.
  • A task only runs on the websites in its address rules. It continues across pages of the same site and stops if the page moves to another site.

3. Values: {{ask}}, counters and test data

  • {{ask}} — ClickRow asks you for the value each time the task runs; it is never saved.
  • {{counter}} — the round number (1, 2, 3…), handy for unique names.
  • Test data such as {{fake:email}} — a new random value each round.

4. Lists: each row in turn and “no more”

  • Each row in turn — when a row’s element matches many items (a button in every line of a table), choose If several match → Each row in turn in the editor. Each round handles the next line; lines that were removed or re-sorted are recognised, disabled lines are skipped.
  • When you record or pick a button inside a list, ClickRow saves it for the whole list rather than for that one line. The page bar says how it was saved and offers a one-click switch between “first row” and “each row in turn”.
  • “No more” is a normal finish — when all lines are done, or the last Next page / Load more button is disabled or gone after at least one full round, the task ends as Finished (no more) instead of failing.

5. Quick fill and auto-run

  • Quick fill — right-click a field → Quick fill with ClickRow → This field, This form or Whole page, or press Alt+Shift+F (Mac: Ctrl+Shift+F) for the whole page. Fields get random test data; passwords, card numbers and codes are never filled. A small panel shows what was filled and skipped, with Undo, Fill again and Save as task. No task is needed.
  • Auto-run — in the editor, turn on Run automatically when a matching page opens. ClickRow asks for access to those sites only (it never asks for all websites). By default it only fills empty fields; the page shows Undo this fill afterwards. Tasks that click delete-type buttons, or that ask for a value at run time ({{ask}}), can’t auto-run because nobody may be there to confirm or answer.

6. Run history

Task menu ⋯ → Run history shows the latest 20 runs of a task: when, how long, how many rounds, and for a failed run the row and the reason. Runs that ended because there was nothing more to do, and runs started by auto-run, are marked. Go to the row that failed opens the editor at that row. Only times, row numbers and reason codes are kept — never what was typed. Quick fill isn’t a task run and isn’t recorded. Clear history deletes them.

7. Keyboard shortcuts

  • Alt+Shift+G (Mac: Ctrl+Shift+G) — run the last task used on the current website.
  • Alt+Shift+S (Mac: Ctrl+Shift+S) — stop the running task.
  • Alt+Shift+F (Mac: Ctrl+Shift+F) — quick fill the whole page.

Change them at chrome://extensions/shortcuts; if another extension already uses a key, Chrome leaves it unset there. Popup Settings shows the current keys.

8. When a row fails (error codes)

When a row fails, ClickRow stops and shows why, with a suggested fix. Each reason has a code; the code in the popup links here.

CodeWhat it meansWhat to do
NOT_FOUNDCouldn’t find the elementIt didn’t show up in time. The page may still be loading, or its layout changed.
NOT_VISIBLEthe element is hiddenIt’s on the page but hidden. It may only appear after another action, or after a short wait.
COVEREDthe element is coveredSomething sits on top of it, so the click lands there instead.
DISABLEDthe element is disabledThe page may enable it after the required fields are filled.
VALUE_NOT_APPLIEDThe value didn’t stick in the elementThe site may reformat or reject scripted input.
NO_EFFECTClicking the element did nothingThe site may ignore scripted clicks. Try a screen position, or add a wait.
STILL_VISIBLEStill on the pageThe element this row waits to disappear is still there. The page may need longer to refresh, or the row before didn’t take effect.
HOVER_NO_MENUHovering over the element didn't open its menuClickRow moved the pointer onto the menu button (then tried the keyboard and a click), but no menu appeared. Some sites only open this menu for a real mouse. Re-pick the menu button, or record a click that opens the menu.
CUSTOM_DROPDOWNthe element is a custom dropdownIt isn’t a standard select box. Click to open, type the option, press Enter.
NOT_EDITABLEthe element can’t be typed intoThis element is not a text field. Re-pick the input box itself.
UNSUPPORTED_FIELDthe element is a field type ClickRow can’t fillFile pickers and similar fields can’t be filled by extensions. Fill this one by hand, or disable the row.
UNSUPPORTED_KEYThis key can’t be pressed by ClickRowUse key names like Enter, Tab, Escape, ArrowDown or Ctrl+A.
ASK_REQUIREDthe element needs a value you type at run timeThis row uses {{ask}}. Run it again and type the value when ClickRow asks — it is never saved.
FRAME_CROSS_ORIGINthe element is inside another site’s frameClickRow can only reach frames from the same site. Open that page directly.
CANVAS_TARGETthe element is a canvas or game areaClickRow clicks and fills elements inside web pages — not games or canvas drawings.
NAVIGATED_AWAYThe page moved to another site at the elementClickRow stops when a task leaves the site it started on.
NAV_TIMEOUTThe next page didn’t load in time after the elementClickRow waits 10 seconds for the next page. Check the page, then continue.
RESUME_FAILEDClickRow couldn’t continue on the new page after the elementReload the page, click the ClickRow icon, then continue.
CURSOR_UNAVAILABLEClickRow couldn’t save its progress at the elementClickRow couldn’t save its progress, so it can’t continue on the next page. Reload the page and run again.
GOTO_CROSS_ORIGINThis go-to row leaves the siteGo-to rows can only open pages on the site the task started on. Change the address to a page on this site.
GOTO_BAD_URLThis go-to row has an invalid addressFix the address in this row — for example https://example.com/form or /form.
GOTO_BAD_PROTOCOLThis go-to row has an unsupported addressGo-to rows only open http:// or https:// pages.
UNSUPPORTED_STEPUnknown row typeThis row was made by a newer or different version of ClickRow. Delete it and add it again.
ERRORRow failed unexpectedlySomething on the page broke this row. Reload the page and try again; if it keeps happening, re-pick the element.
ACTION_ERRORRow failed unexpectedlySomething on the page broke this row. Reload the page and try again; if it keeps happening, re-pick the element.
TAB_CLOSEDThe tab was closed while the task was runningShown in run history only. Keep the tab open until the run finishes.
INTERRUPTEDThe run was interruptedShown in run history only. The page reloaded or the browser stopped the run. Run the task again.
